# AI emblems

Local, offline brand symbols for the decorative bar rotation. Trademarks remain
the property of their owners; inclusion does not imply endorsement. Retrieved
2026-10-17. Paths retain the source geometry; viewBoxes trim whitespace and the
bar applies a monochrome tint and per-symbol optical sizing.

- OpenAI, OpenCode, Cursor, Claude: [LobeHub icons](https://github.com/lobehub/lobe-icons),
  MIT, commit `8a1b2821bb768c484fe8da20c5e1838b6bf551a9`,
  `packages/static-svg/icons/{openai,opencode,cursor,claude}.svg`.
  `currentColor` is replaced with black as an explicit alpha-mask fill.
  OpenCode uses the hollow monochrome symbol, not the two-tone console asset:
  flattening that asset's colors filled the opening and distorted the mark.
  Its viewBox trims empty margins without altering the path.
- Antigravity: [Google press kit](https://antigravity.google/press/),
  `https://antigravity.google/assets/image/brand/antigravity-icon__one-color.svg`.
  Google brand asset; no open-source license asserted. Subject to Google's
  applicable brand terms. Only its empty viewBox margins were trimmed.
- Zed: [official repository](https://github.com/zed-industries/zed), commit
  `56934ec0560bce8929025497411de7f5322fb6ca`,
  `assets/images/zed_logo.svg`. Removed redundant viewBox clipping. The source
  repository provides GPL-3.0 and Apache-2.0 licenses; no separate trademark
  permission is asserted. This repository is distributed under GPL-3.0.
